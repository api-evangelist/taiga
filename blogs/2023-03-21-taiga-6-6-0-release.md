We’ve got some news for you! Although the Taiga team is currently focused on TaigaNext and not developing any new features for Taiga6, we have made some interesting changes for the self-hosted instances in the past few weeks . Firstly, we’ve migrated the Taiga6 API to Django 3.2 and upgraded many dependencies to their newer and more secure versions.
